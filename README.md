# 🐍 Ejercicios Básicos con Bucles For en Python

Ejercicios de práctica para aprender a usar bucles `for` en Python,
cubriendo distintos casos de uso desde lo más simple hasta lógica condicional.

## 📋 Ejercicios

| N° | Nombre | Descripción |
|----|--------|-------------|
| 1 | Básico | Imprime los números enteros del 0 al 100 |
| 2 | Múltiples de 2 | Imprime los múltiplos de 2 entre 2 y 500 |
| 3 | Contando Vanilla Ice | Reemplazo de números por texto según divisibilidad |
| 4 | Número gigante | Suma todos los números pares del 0 al 500.000 |
| 5 | Regrésame al 3 | Cuenta regresiva desde 2024 de 3 en 3 |
| 6 | Contador dinámico | Filtra múltiplos entre dos números configurables |

## 🚀 Cómo ejecutarlo

1. Cloná el repositorio o descargá el archivo
2. Abrí una terminal y navegá hasta la carpeta
3. Ejecutá el siguiente comando:
python bucle_for_basico1_tarea.py
## 🛠️ Requisitos

- Python 3.14
